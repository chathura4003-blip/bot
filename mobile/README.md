# 🚀 Cloud Drive Leech - Mobile & Web App

High-Speed Cloud ➔ Google Drive Movie, Media & 18+ Downloader Application (Zero WhatsApp Bot dependencies).

---

## 🌟 Features

1. **🎬 Sinhala Sub & Global Movie Hub**:
   - Live search for movies on Sinhalasub, Baiscope, etc.
   - 480p, 720p, 1080p quality selector.
   - 1-Click transfer from Cloud directly to Google Drive.

2. **⚡ Universal Media Downloader**:
   - Supports YouTube, TikTok, Facebook, Instagram, Twitter, Mega, PixelDrain, and direct links.
   - Instant format & audio/video extraction.

3. **🔞 18+ Adult Video Hub**:
   - Fast 18+ video search & stream resolver.
   - 1-Click background download to Google Drive.

4. **📊 Real-time Cloud Transfer Dashboard**:
   - Dual progress monitor (Cloud download speed & Google Drive upload speed).
   - Generates Direct Google Drive Download Links (Full speed & resume support in IDM/Browser).

5. **📁 Google Drive Explorer**:
   - Browse files stored in your Drive folder.
   - 1-Click copy link or stream video directly in browser.

---

## 🚀 How to Run

1. Open terminal inside `mobile/` or double-click `start-mobile.bat`:
   ```bash
   cd mobile
   node server.js
   ```
2. Open in your phone or PC browser:
   ```
   http://localhost:3000
   ```
3. To install on phone as an app:
   - Open Chrome on mobile ➔ Tap three dots ⋮ ➔ **"Install App"** / **"Add to Home Screen"**.
