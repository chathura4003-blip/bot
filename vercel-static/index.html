This deployment can't run on Vercel

Chathu MD is a long-running WhatsApp bot with a live socket connection and local session storage. Vercel Functions are stateless and short-lived, so the bot can never stay connected here — this isn't a bug to patch, it's a platform mismatch.

Why it can't run as a function

  • Keeps a persistent WhatsApp Web socket open 24/7 — functions terminate after each request.
  • Writes session/auth state to the local filesystem — Vercel's filesystem is read-only and ephemeral.
  • The live dashboard relies on a persistent socket.io connection for real-time updates.
